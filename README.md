# mailreader

mailreader is a small program that Xiaozhen Liu wrote for his own use. It runs on his own
computer and lets the AI assistant he works with search and read his own mailboxes. It is not
a product or a service, and it is not offered to anyone else.

## What it does

It can list accounts, search messages, read a message and read a conversation. It cannot send,
change or delete mail: it contains no code for that, and for a Google account it asks Google
only for the read-only permission (`gmail.readonly`).

## Where it runs

Only on the owner's computer. There is no server behind it.
